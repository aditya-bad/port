## Develop and test (sandbox or laptop)

```bash
service postgresql start                      # if Postgres stopped
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
sudo -u postgres createuser -P t              # password t
sudo -u postgres createdb -O t t_test
sudo -u postgres psql -c 'ALTER ROLE t CREATEDB'
(cd tests/e2e && npm install)                 # browser tests

PYTHON=.venv/bin/python E2E_SHARDS=1 ./run_tests.sh --e2e   # the gate
.venv/bin/python -m pytest tests/unit                       # quick
E2E_SHARDS=1 E2E_SPECS="./shadow.e2e.mjs" tests/e2e/run.sh  # one browser spec
node --test --test-force-exit tests/js/*.test.mjs
```

Run the app locally: `cp config.example.json config.json`, fill it in, then
`python run.py` (or `uvicorn app.main:app --port 8000` from `live_deploy/`).
Migrations apply themselves on startup.

## Deploy (the owner only)

On the box, in `live_deploy/`, outside market hours (after 15:30 or before
09:00; mid-day is possible in a quiet window, see below):

```bash
git branch --show-current        # must be claude/nifty-shop-port-setup-xkdq22 (or merged)
./run_tests.sh                   # optional
./redeploy.sh                    # pull, rebuild, restart; migrations run on start
docker logs --tail 50 live-deploy   # look for applied migrations, resumed deployments
```

Then log in to Kite if before 09:15. Mid-day: build first
(`docker build -t live-deploy .`) then `./redeploy.sh --no-pull`; avoid
09:15–10:15 and 15:00–15:30. Account → Server → Redeploy in Linck does the
same through `redeploy_watcher.sh`.

## Kite

- Daily login in the app (header Kite chip, Account → Kite, or the Connect
  Kite step after sign-in): Zerodha popup or paste the `request_token` /
  redirect URL. The token is stored in Postgres; the feed hot-swaps.
- Redirect URL registered in the Kite developer console:
  `http://<host>:8000/kite/callback`.
- Mark as holiday mutes alerts until 07:00 next day.

## Useful scripts (run in the container; `--dry-run` first)

| Script | Does |
|---|---|
| `custom_scripts/day_check.py` | The end-of-day check (normally launched after the 15:45 export) |
| `custom_scripts/repair_stall.py --date YYYY-MM-DD --from HH:MM [--probe] [--verbose]` | CLI repair; always pass `--date` |
| `custom_scripts/shadow_backfill.py --dry-run` | Estimate shadow verdicts for past fills |
| `custom_scripts/import_candles.py --all-trades --min-expiry DATE` / `--kite-since DATE` / `--csv DIR` | Fill the candle store |
| `custom_scripts/fix_carried_intraday_legs.py [--fix]` | Report/correct legs carried past the square-off |
| `custom_scripts/backfill_estimated_charges.py --dry-run --sample N` | Charges backfill with per-deployment and per-type breakdown |
| `custom_scripts/slippage_report.py --days 7 --fills 10` | Slippage audit |
| `custom_scripts/remove_todays_trades.py`, `recreate_deployment_clean.py`, `close_stuck_strangle_leg.py` | One-off fixes |

Example: `docker exec -it live-deploy python3 custom_scripts/repair_stall.py --date 2026-10-21 --from 12:16`.
